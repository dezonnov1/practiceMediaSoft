/01 Задача: Java SE
Условия:
Необходимо реализовать приложение,
которое загружает и обрабатывает
информацию о рабочем времени летных
специалистов авиакомпании.

Входные данные приложение загружает из файла, в котором хранится
- список летных специалистов
- список перелетов, которые были выполнены самолетами авиакомпании.

Для каждого перелета указывается
- тип воздушного судна
- номер воздушного судна
- время взлета
- время посадки
- название аэропорта вылета
- название аэропорта назначения
- список экипажа, выполнявшего перелет

Приложение считывает данные из файла,
после чего формирует выходной файл в
формате XML или JSON (на выбор).

В выходном файле для каждого летного
специалиста должно быть указано:
-полетное время за каждый месяц, указанный во входном файле
(то есть, если
во входном файле указаны перелеты,
выполненные в декабре 2020, январе 2021
и феврале 2021, для каждого специалиста
должно быть указано полетное время за
декабрь 2020, январь 2021 и февраль 2021).

Также, для каждого месяца у каждого
специалисты должны быть ОСОБЫЕ ОТМЕТКИ
в том случае:
- в данном месяце суммарное рабочее время превышает 80 часов.
- в данном месяце были недели, когда суммарное рабочее время превысило 36 часов.
- в данном месяце были дни, когда суммарное рабочее время превысило 8 часов.

Задача должна быть решена
исключительно средствами Java SE, код
приложения должен содержать unit-тесты,
приложение должно собираться при
помощи Maven или Gradle.
