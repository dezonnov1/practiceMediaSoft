## Установка
1. Запуск Intelij IDEA community.
2. Открываем проект.
3. Устанавливаем зависимости
    - Вписать в терминал IDE:
      
       >cd [путь до проекта]\practiceMediaSoft
       >
       >mvn clean install
4. запускаем jar из папки target.
5. Пример запуска:
   - [путь до проекта]/target/practiceMediaSoft-1.0-SNAPSHOT.jar data.json out.json
6. особенности:
   - для ввода и вывода используется папка пользователя
